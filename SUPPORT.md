# 🆘 Support

## Before Asking for Help

1. Read the [README](README.md).
2. Review the [Documentation Index](docs/README.md).
3. Check [Troubleshooting](docs/troubleshooting.md) and [FAQ](docs/faq.md).
4. Search existing GitHub issues.

## Information to Include

For a Power BI issue:
- Power BI Desktop version.
- Operating system.
- Affected PBIX page, query, visual, or measure.
- Source file used (CSV/XLSX/database).
- Refresh timestamp and error text.
- Reproduction steps.
- Expected and actual result.
- Sanitized screenshots.

For a data issue, include source file/version, exact field, sample values with sensitive information removed, row counts, and the transformation involved.

For a SQL issue, include database engine/version, SQL dialect, schema dependency, and sanitized error text.

## Where to Ask

Use GitHub Issues for reproducible bugs, feature requests, and documentation improvements. Select the appropriate issue template.

## Privacy and Security

Do not attach confidential datasets, customer records, connection credentials, or private exports. Use [SECURITY.md](SECURITY.md) to report suspected vulnerabilities or data exposure privately.

## Scope

The repository contains an analysis project, not an official Amazon reporting system or a hosted Power BI service. Questions about upstream data provenance may require confirmation from the original data provider.
