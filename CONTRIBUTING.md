# Contributing

Contributions should improve the dashboard's clarity, reproducibility, and data quality without misrepresenting the source data.

## Before changing the report

- Read the README and data documentation.
- Keep raw source files unchanged unless the change is explicitly documented.
- Do not commit credentials, private exports, customer data, or unlicensed assets.
- Record Power BI Desktop version, refresh date, and source-path changes.

## Pull requests

Describe changed visuals, measures, transformations, and assumptions. Include before/after screenshots for report changes and explain how the data was validated. For SQL changes, state the target dialect and whether the script is read-only or mutates data.
