# Data, Brand, and Asset Licensing

## Scope

The repository includes a dataset, Power BI/PDF outputs, and image assets. The legal status of each component should be checked independently before redistribution.

| Artifact | Review required |
|---|---|
| CSV/XLSX data | Source provenance, dataset license, redistribution and derived-use rights |
| PBIX/PDF | Embedded data rights, visuals, report content, and metadata |
| Amazon-Logo.png | Trademark/logo permissions and allowed use |
| Amazon Background.jpg | Image source and redistribution rights |
| Project_Img.png | Creator/source and reuse permission |
| LICENSE | Applies to project-authored material as stated; does not supersede external terms |

## No Assumed Provenance

The repository name and filenames are not proof that data originated from Amazon or is an official Amazon dataset. Do not label it official, audited, or authorized without independent evidence.

## Verification Procedure

1. Identify source URL, author, publisher, or supplier for each dataset/asset.
2. Read the applicable license or obtain written permission.
3. Record attribution and redistribution obligations.
4. Confirm trademark/brand restrictions.
5. Replace assets whose use cannot be justified.
6. Keep evidence of permission outside public commits if confidential.
