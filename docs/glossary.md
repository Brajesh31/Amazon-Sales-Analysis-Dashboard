# Glossary

| Term | Meaning |
|---|---|
| PBIX | Power BI Desktop report file containing report/model content |
| PDF export | Static document snapshot of report pages |
| Power Query | Power BI data connection and transformation experience |
| Data model | Tables, relationships, measures, and metadata used by a report |
| DAX | Data Analysis Expressions used in Power BI measures/calculated objects |
| Measure | Calculation evaluated in the report's current filter context |
| Calculated column | Row-level expression stored in a model table |
| Slicer | Report visual used to filter other visuals |
| Filter context | Active filters that affect measure results |
| Cross-filtering | A selection in one visual changes another visual's result |
| CSV | Text-based tabular format |
| XLSX | Microsoft Excel workbook format |
| Data lineage | Traceability from source through transformations to report |
| Staging table | Intermediate database table before final loading |
| Data dictionary | Field-level definitions, types, units, and caveats |
| Row grain | Meaning represented by one row in a dataset |
| Reconciliation | Independent comparison of expected and reported values |
| Refresh | Re-querying sources and updating the Power BI model |
| Gateway | Power BI connectivity component for sources requiring gateway access |
| Semantic model | Tables, measures, relationships, and metadata used by a report |
| Provenance | Evidence about where data or an asset originated |
| Static snapshot | Export that does not update when the source/report changes |
| KPI | Key performance indicator with an explicit business definition and calculation |
