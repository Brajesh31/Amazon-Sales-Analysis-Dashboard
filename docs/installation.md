# Installation

## Dashboard

Install Power BI Desktop on a supported Windows system and open `Amazon.pbix`. If the report cannot locate its source, reconnect it to `Amazon_Combined_Data.xlsx` or the CSV and refresh.

## SQL

Install an authorized MySQL-compatible environment only if you need to execute `Amazon Database.sql`. Review every statement before execution; the script creates/selects a database and queries a table but does not load data.
