# Security Policy

## Data handling

Treat the CSV, XLSX, PBIX, PDF, and image assets as potentially sensitive analytical artifacts. Do not add customer identifiers, credentials, private exports, connection strings, or unpublished business data. Review Power BI data sources and hidden model fields before sharing a PBIX file.

The repository is an educational dashboard and is not an official Amazon reporting system. Validate data provenance and access rights before redistribution.

## Reporting

Report suspected data exposure, credential leakage, or unsafe query behavior privately to Brajesh Kumar (`@brajesh31`). Include affected files and reproduction details without attaching confidential data.
